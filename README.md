# NETWORKWALKS – B083 – Week 1: Cybersecurity Lab Setup

## 📌 Overview

This repository documents my hands-on learning experience during **Week 1 of the NETWORKWALKS Cybersecurity Internship**.

The lab focused on setting up a virtualized Android OS environment using VirtualBox, configuring network connectivity, and establishing communication between Android OS and Kali Linux.

## 🎯 Objectives

* Set up a virtualized cybersecurity lab environment.
* Deploy Android OS using VirtualBox.
* Configure NAT networking and IP settings.
* Verify connectivity between Android OS and Kali Linux.
* Troubleshoot virtual machine and network configuration issues.

## 🛠️ Tools and Technologies

| Tool / Technology | Purpose                                   |
| ----------------- | ----------------------------------------- |
| VirtualBox        | Virtual machine deployment and management |
| Android OS        | Target virtual machine environment        |
| Kali Linux        | Cybersecurity testing environment         |
| NAT Networking    | Virtual machine network connectivity      |
| IP Configuration  | Network setup and communication testing   |

## 🔧 Lab Activities

1. Downloaded and prepared the Android OS archive.
2. Installed and configured Oracle VirtualBox.
3. Created and deployed an Android OS virtual machine.
4. Configured NAT networking.
5. Configured the IP settings for Android OS.
6. Performed connectivity checks between Android OS and Kali Linux.
7. Troubleshot configuration issues encountered during the setup.


## Learning Outcomes

Through this lab, I gained practical exposure to:

* Virtual machine deployment and configuration.
* Basic network setup and IP addressing.
* NAT-based networking.
* Connectivity troubleshooting.
* Preparing a foundation for future cybersecurity labs.
